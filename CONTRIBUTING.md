# Contributing

Contributions and suggestions are welcome! If you find any mistakes in the content, such as spelling or grammar errors, feel free to [create a new pull request](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request).

## Branch Naming

This repository follows the [Conventional Branch](https://conventionalbranch.org) specification.

Examples:

```text
feat/search
fix/mobile-navigation
content/my-project
chore/update-deps
docs/update-readme
```

## Commit Messages

This repository follows the [Conventional Commits](https://www.conventionalcommits.org/) specification.

Examples:

```text
feat(search): add keyboard shortcut
fix(posts): correct reading time calculation
refactor(projects): simplify project card
content(project): update my-project case study
content(post): publish initial-commit
content(skill): remove Java
content(cv): update work experience
chore(deps): update astro from 1.0.0 to 1.1.0
docs(readme): update description
```
