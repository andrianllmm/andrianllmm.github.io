UniGlyphs is a browser extension that lets users style and format text anywhere.
It provides a floating toolbar that works on websites like Facebook, along with a full-page and popup editor in the browser.
Users can write expressive posts, comments, and more—even on platforms that don’t allow custom fonts.
Styled text is generated using Unicode characters that resemble different font styles, such as 𝐛𝐨𝐥𝐝, 𝑖𝑡𝑎𝑙𝑖𝑐, and 𝔤𝔬𝔱𝔥𝔦𝔠, which persists their look across platforms.
It was initially developed as a final project for <a href="https://cs50.harvard.edu/x/2025" target="_blank">Harvard's CS50x</a>.[^1]
It is now a reusable tool in the <a href="https://chromewebstore.google.com/detail/hcnbmicjiggmklnmkpljeomkmagigkbc" target="_blank">Chrome Web Store</a>.
