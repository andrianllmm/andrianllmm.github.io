Pydoku is a Sudoku game built in Python using <a href="https://docs.python.org/3/library/tkinter.html" target="_blank">Tkinter</a>.
It generates random puzzles, lets users solve them, and offers hints. It also includes a solver that uses backtracking to find solutions.
The interface is designed to be minimal and easy to use.

## Why I built it

Pydoku was built as a final project for <a href="https://upvdpsm.com/courses/computer-science/cmsc-11.html" target="_blank">CMSC 11</a>
(Introduction to Computer Science).[^1]
The task was to create a <abbr title="Graphical User Interface">GUI</abbr> using Tkinter and Python fundamentals that we learned in the class.
