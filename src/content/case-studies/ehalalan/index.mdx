eHalalan is a decentralized election system that uses blockchain technology to ensure transparency and security.

## Why we built it

eHalalan was built as a hackathon project for the <a href="/achievements/komsaihack25" target="_blank">KomsaiHack 2025: Democratech Hackathon</a>.

We chose to build an e-voting system because we believed that it would be a great opportunity to learn about blockchain technology
and its potential applications in the real world.
